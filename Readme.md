# Students Performance - Exploratory Data Analysis (EDA)

## Project Overview
This project explores the Students Performance dataset using Python to understand students' academic performance and identify patterns and relationships between different variables.

## Objectives
- Explore and understand the dataset.
- Check data quality (missing values, duplicates and invalid values).
- Analyze students' performance in mathematics, reading and writing.
- Compare academic performance by gender and other categories.
- Visualize distributions and relationships between variables.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Data exploration
- Data cleaning and validation
- Descriptive statistics
- Grouping and aggregation
- Data visualization
- Interpretation of results

## Key Findings
- Male students have a higher average mathematics score.
- Female students have higher average reading and writing scores.
- Academic performance varies across race/ethnicity groups.
